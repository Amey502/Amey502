### 🚀 Featured Projects

**IntelliNotes — AI-powered Collaborative Learning Platform**

A collaborative learning platform featuring team workspaces, secure note sharing, PDF uploads, automatic summarization, and context-aware question answering using Django, Hugging Face, and locally hosted Ollama models.

**Document Q&A System — Hybrid RAG**

A document question-answering system combining FAISS semantic search, BM25 keyword retrieval, and CrossEncoder reranking, with OCR-supported PDF ingestion and dynamic index updates.

**MoodWeather**

A neural-network-powered application that combines real-world weather parameters with PyTorch inference to generate poems based on a location's weather.

**EduDesk**

A desktop-based record management application built using Python, Tkinter, and MySQL, featuring authentication and administrative CRUD operations for student and teacher records.
